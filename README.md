# Python Basic Calculator

A small command-line calculator built with Python functions and conditional statements.

## Operations

- Addition
- Subtraction
- Multiplication
- Division

## Concepts practised

- Function definitions and return values
- Numeric input and type conversion
- Conditional branching
- Basic arithmetic operations

## Run locally

```bash
git clone https://github.com/sai-manikanta-kadali/calculator_python-project.1-.git
cd calculator_python-project.1-
python3 calculator_project.py
```

No external dependencies are required.

## Current scope

This is a foundational console exercise. It does not yet include a graphical interface, expression parsing, or explicit handling for division by zero.
